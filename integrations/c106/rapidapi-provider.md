# RapidAPI provider preflight

Define a narrow PT-BR speech-to-text or diarization contract before applying
to a marketplace. Keep the provider configuration separate from the owned
checkout and never place a secret in a README or fixture. Marketplace search,
API calls, and subscriptions are not reconciled cash until payout evidence is
available.

- [What is RapidAPI](https://docs.rapidapi.com/docs/what-is-rapidapi)
- [Provider dashboard](https://docs.rapidapi.com/v1.0/docs/provider-dashboard)
- [Creating and updating APIs](https://docs.rapidapi.com/docs/creating-updating-apis)

Account, plan, support, compliance, and review are explicit gates. No listing
or revenue is claimed until a receipt exists.
