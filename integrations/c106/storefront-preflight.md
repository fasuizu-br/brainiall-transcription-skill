# Alternative storefronts

Firefox Add-ons, Edge Add-ons, F-Droid, and Apple App Store can expose
searchable demand, but each has identity, package, privacy, review, and (for
some surfaces) paid developer gates. Start with a no-spend fixture and an
owned CTA; do not pay a developer fee or submit without explicit approval.

- [F-Droid submission guide](https://f-droid.org/en/docs/Submitting_to_F-Droid_Quick_Start_Guide/)
- [Edge extension publishing](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension)
- [Apple review guidelines](https://developer.apple.com/app-store/review/guidelines/)

An install or review approval is not a buyer. Preserve route-level intent and
reconcile Stripe, payout, and bank settlement independently.
