# Zoom Marketplace · transcript QA (C97)

Recipe público para operadores de webinar que precisam revisar transcript e SRT antes do replay.

## Limites

- Use somente uma gravação que o operador controla ou tem autorização para processar.
- Apps públicos exigem review de metadados, segurança e funcionalidade, além de termos, privacidade e suporte.
- Nenhum Zoom app foi publicado por este arquivo.

## Fluxo

1. Fixe a gravação e a retenção autorizadas.
2. Gere e revise transcript, falantes e timing.
3. Abra o checkout próprio apenas após o primeiro valor.
