# Figma · caption proof (C97)

Recipe público para transformar uma saída autorizada de transcript/SRT em uma prova visual de caption QA.

## Limites

- A fixture deve ser pública ou autorizada; nenhum áudio privado é enviado por este recipe.
- A publicação no Figma Community depende de desktop app, criador aprovado, 2FA e review.
- A página não afirma plugin publicado, pago ou aprovado.

## Fluxo

1. Gere ou forneça um transcript autorizado.
2. Monte o frame de prova e compare texto, falantes e timing.
3. Meça CTA/first value antes de qualquer checkout.
