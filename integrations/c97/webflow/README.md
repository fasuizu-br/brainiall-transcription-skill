# Webflow Apps · caption metadata (C97)

Blueprint de Designer Extension para preparar metadata e captions PT-BR no handoff de uma agência.

## Limites

- App registration exige Workspace admin e a publicação exige review do Marketplace.
- O recipe não pede acesso a site de cliente, CMS, token ou segredo.
- Não afirma listing, instalação ou monetização no Webflow.

## Fluxo

1. Escolha arquivo autorizado e destino CMS.
2. Revise SRT/VTT e metadata antes do upload sob controle do cliente.
3. Meça CTA e primeiro valor no host Brainiall.
