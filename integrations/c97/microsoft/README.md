# Microsoft Teams / AppSource · captions (C97)

Blueprint de manifesto e handoff para equipes Microsoft 365 que precisam revisar captions PT-BR.

## Limites

- O arquivo não solicita tenant, OAuth, escopo ou credencial.
- Partner Center, validação do manifesto e Teams Store/AppSource review são gates externos.
- Não há alegação de publicação ou uso em cliente.

## Fluxo

1. Use gravação autorizada e mantenha o transcript revisável.
2. Valide falantes, timing e formato SRT/VTT.
3. Meça o primeiro valor no host e só então avalie créditos ou piloto.
