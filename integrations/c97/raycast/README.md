# Raycast · caption QA PT-BR (C97)

Receita pública para operadores que querem revisar transcript e SRT de um arquivo autorizado a partir de um comando Raycast.

## Limites

- Não inclui token, segredo, áudio privado ou login de terceiro.
- A publicação no Raycast Store exige build local, PR e revisão dos mantenedores; este arquivo não afirma aceite.
- O resultado automático exige revisão humana antes de publicar.

## Fluxo

1. Use uma fixture pública ou um arquivo que a equipe controla.
2. Chame o endpoint/Actor de transcrição da BRAINIALL fora do comando com credencial mínima.
3. Revise falantes, termos e timing e só então abra o checkout próprio.
