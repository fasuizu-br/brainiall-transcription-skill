# Google Workspace · transcript add-on (C97)

Blueprint de Apps Script para mover um arquivo autorizado do Drive para um transcript revisável no Docs.

## Limites

- Use escopos OAuth mínimos e uma conta/domínio sob controle do operador.
- O Marketplace público exige projeto Cloud, OAuth e app review; esta receita não cria add-on nem concede acesso.
- Não coloque credenciais, tokens ou conteúdo privado neste repositório.

## Fluxo

1. Fixe proprietário, retenção e arquivo de entrada.
2. Execute a etapa de transcrição com o serviço do operador.
3. Revise o documento e registre primeiro valor, checkout e pagamento separadamente.
