# Atlassian Forge · transcript handoff (C97)

Recipe de app Forge para anexar transcript e evidência de caption QA a Jira ou Confluence.

## Limites

- Instale somente em um site Atlassian que a equipe administra.
- Vendor profile, Marketplace agreement, listing e approval são gates externos.
- Este repositório não inclui token, descriptor de cliente ou claim de listagem.

## Fluxo

1. Escolha um issue/página e um arquivo autorizado.
2. Anexe apenas a saída revisada e mantenha o original sob controle do cliente.
3. Registre intenção e checkout no host Brainiall; o Marketplace não é prova de receita.
