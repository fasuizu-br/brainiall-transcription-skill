# C108 ecommerce caption pilot

The pilot is for one Shopify or WooCommerce agency that already owns the
client relationship. The agency supplies a creator-owned video and receives a
reviewable transcript, SRT or VTT before a quote is made.

- One deduped, permissioned contact; no store scraping or mass outreach.
- Use staging or a local export; never request merchant passwords.
- Explain the exact file limit, human-review boundary and retention policy.
- A marketplace submission, install or referral is not a buyer event.
- Route payment through the Brainiall checkout and count only settled,
  reconciled cash.
