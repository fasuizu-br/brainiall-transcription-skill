# C108 app-marketplace preflight

This note compares Stripe Apps, Shopify, WooCommerce, Bubble, Notion,
Webflow, Miro and Canva as discovery surfaces for a narrowly defined
transcript job. It is not a claim that Brainiall has been listed or approved.

## Safe sequence

1. Start with a local or sandbox fixture and one authorized file.
2. Record first value and a price question before creating an external app.
3. Read each surface's current review, billing, OAuth and permission rules.
4. Keep secrets server-side and request the least-permissive scope.
5. Treat installs, reviews, listings, app analytics and checkout redirects as
   non-revenue until a buyer's payment is settled and independently reconciled.

Official references: [Stripe Apps](https://docs.stripe.com/stripe-apps/publish-app), [Shopify](https://shopify.dev/docs/apps/launch/shopify-app-store/app-store-requirements), [WooCommerce](https://developer.woocommerce.com/docs/woo-marketplace/submitting-your-product), [Bubble](https://manual.bubble.io/account-and-marketplace/building-plugins/the-plugin-editor), [Notion](https://developers.notion.com/guides/get-started/marketplace-listing), [Webflow](https://developers.webflow.com/data/v2.0.0-beta/apps/docs/private-apps), [Miro](https://developers.miro.com/docs/miro-marketplace), and [Canva](https://www.canva.dev/docs/apps/submission-checklist/).
