# C105 Hugging Face Space blueprint

The Space should demonstrate one authorized sample and show transcript plus
SRT output, with an explicit link back to the Transcreve BR checkout. Keep the
source public only when it contains no secrets and state any model/API cost.

## Gate

Space creation and upload require the corporate Hugging Face account. Record
the Space URL, version, sample run and first-value event; views, likes and
clones alone are not revenue.

Reference: <https://huggingface.co/docs/hub/main/spaces-overview>.
