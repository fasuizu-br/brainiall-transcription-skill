# C99 — automation marketplace preflight

Compare three demand surfaces before building a full integration:

- Zapier: build and test a public integration, then submit it for review.
- Make: create a custom app and publish only when the irreversible publication gate is understood.
- RapidAPI: package a metered endpoint with clear plans and support boundaries.

For each surface, record: audience, job, activation event, first-value artifact, attribution intent, review/account gate, and path to paid usage. Do not call a directory listing, invite link, app approval, API call, payout, or reconciliation a success without its own receipt.
