# C99 — n8n transcription node recipe

This recipe is for a self-hosted n8n HTTP Request or community-node experiment.

## Suggested node contract

- audio: binary property containing an authorized file
- language: pt for Brazilian Portuguese when known
- diarize: explicit boolean, default false
- response: transcript words, timestamps, speakers when requested, and export URL/artifact

Keep credentials in n8n credentials or environment variables. Do not paste keys into a workflow export. Run a fixture, inspect the artifact, and only then estimate monthly volume. Track c99|n8n|br|automation on the own-site CTA.

This is not an n8n review or catalog acceptance. Official reference: https://docs.n8n.io/integrations/community-nodes/
