# C104 editorial recipes

These recipes describe a permission-first path for DEV, Hashnode, HackMD, and
similar technical publishing workflows. They are intended for an author who
already owns the recording and wants a transcript as a revisable source, not
for automatic publishing or scraping.

1. Keep the original recording local and confirm rights.
2. Run the existing skill once with a dedicated `BRAINIALL_API_KEY`.
3. Review transcript, speaker labels, SRT, and VTT.
4. Publish only the author's own article or note and retain the canonical URL.

Current surface rules are authoritative: [DEV API docs](https://developers.forem.com/api/),
[Hashnode editor docs](https://docs.hashnode.com/blogs/editor/writing-a-blog-post),
and [HackMD](https://hackmd.io/). A pageview, article, or note is not a buyer
and no platform publication is claimed by this file.
