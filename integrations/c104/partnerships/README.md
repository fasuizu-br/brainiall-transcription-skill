# C104 OSS issue and partner protocol

Use this protocol only when a public issue or maintainer request identifies a
matching transcription/caption problem. First inspect the current state and
comments, deduplicate any prior BRAINIALL response, and check the project's
promotion rules. If eligible, one short corporate disclosure may offer an
opt-in fixture; do not send credentials, private audio, unsolicited follow-ups,
or an unverified compatibility claim.

Record the issue URL, timestamp, exact comment, response, CTA, and whether a
separate buyer completed payment and settlement. A closed issue, an existing
BRAINIALL comment, or a maintainer decision that makes the offer irrelevant is
a gate, not a reason to post again.
