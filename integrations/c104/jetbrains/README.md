# C104 JetBrains transcript blueprint

This note maps a possible JetBrains action to the existing local skill. It is
not a plugin, Marketplace submission, approval, installation, or sales claim.

## Narrow job

From the IDE, a user selects one rights-cleared recording, follows the skill's
consent and language checks, and reviews the generated JSON/SRT/VTT outside the
IDE. Caption QA remains local and semantic accuracy still requires a human.

## Publication gates

Before any plugin code, collect evidence of a recurring job and a willingness
to pay. A real plugin would need a vendor profile, developer agreement,
license/EULA, review, secure secret handling, and a rollback path. Check the
[official upload requirements](https://plugins.jetbrains.com/docs/marketplace/uploading-a-new-plugin.html)
at the time of submission; this repository intentionally does not access an
account or submit anything.
