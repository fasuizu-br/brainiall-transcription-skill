# Pipedream component blueprint (C96)

A no-secret action shape for caption QA and a hosted PT-BR transcription handoff.

Action inputs: authorized fixture reference, language=pt-BR, and output format=srt|vtt. The action should return structural QA only; it must not publish a caption or claim semantic accuracy.

Discovery page: https://www.brainiall.com/transcreve/integracoes/pipedream-component-c96.

Registry contribution requires the Pipedream component guidelines, unique key, semantic version, and review. No registry acceptance is claimed.
