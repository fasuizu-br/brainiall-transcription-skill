# Make Custom App blueprint (C96)

Credential-free outline for a Make custom app that exposes PT-BR transcription and caption QA as explicit modules.

Modules: transcribe_ptbr, caption_qa, and export_reviewed_caption. The first fixture must be authorized and the output must be reviewed by the operator.

Discovery page: https://www.brainiall.com/transcreve/integracoes/make-community-app-c96.

Make publication, invite links, partnership, and QA review are external gates. This file does not claim a public Make listing and contains no credentials.
