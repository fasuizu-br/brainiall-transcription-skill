# VS Code caption QA extension recipe (C96)

Local-first extension outline for checking SRT and WebVTT structure inside VS Code.

The extension must not upload a file automatically. It can open the hosted Transcreve route only after the operator explicitly chooses the next step.

Discovery page: https://www.brainiall.com/transcreve/integracoes/vscode-caption-qa-extension-c96.

A VSIX can be owner-tested locally. Marketplace publication requires publisher registration and Microsoft/Azure DevOps authentication; no Marketplace listing is claimed.
