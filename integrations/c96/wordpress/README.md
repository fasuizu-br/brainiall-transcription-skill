# WordPress caption QA plugin recipe (C96)

Recipe for a local preflight block that checks SRT/WebVTT before a WordPress video embed is published.

The checker should preserve user text locally, report structural errors, and require an explicit handoff for new transcription. It must not send private audio without consent.

Discovery page: https://www.brainiall.com/transcreve/integracoes/wordpress-caption-qa-plugin-c96.

The WordPress.org directory requires a readme, guideline compliance, and review. This repository is a recipe, not an approved directory plugin.
