# Dify GitHub-first recipe (C96)

A bounded recipe for a Dify workflow using an HTTP step for PT-BR transcription and a local caption QA step.

Privacy boundary: send only an authorized test object; do not paste private audio or API keys into prompts or repository files. Treat transcript and captions as review-required output.
