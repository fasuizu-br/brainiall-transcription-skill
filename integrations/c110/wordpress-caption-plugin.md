# WordPress caption handoff fixture

An importable content workflow for publishers who need captions for one
authorized recording. It deliberately avoids an unattended plugin install or
an assertion that WordPress.org has approved a listing.

## Test

1. Export a local SRT or WebVTT from the existing skill after rights and
   language checks.
2. Import it into a staging post and run the repository caption QA helper.
3. Ask the publisher to opt in to a bounded pilot before discussing a paid
   plan; do not scrape audiences or send duplicate outreach.

## Evidence

Keep the source URL, fixture hash, QA result, buyer-linked checkout ID,
settlement ID, and bank reconciliation evidence separate. Traffic and a
successful import alone do not qualify as revenue.
