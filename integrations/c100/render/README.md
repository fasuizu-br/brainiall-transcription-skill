# Transcreve BR — Render Blueprint recipe (C100)

This recipe is a minimal, provider-neutral Blueprint outline for a transcription worker and callback service. It does not deploy to a Render account.

Test the public first-value flow before configuring an external service:

https://www.brainiall.com/transcreve/integracoes/render-blueprint-transcribe-c100

Source rule: follow the [Render Blueprint specification](https://render.com/docs/blueprint-spec) and keep secrets in the destination account.
