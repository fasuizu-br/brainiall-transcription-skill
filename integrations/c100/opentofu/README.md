# Transcreve BR — OpenTofu module recipe (C100)

This recipe is a public, provider-neutral starting point for teams that want to provision a transcription worker with versioned variables, callbacks, and health checks.

It does not publish a provider or module to the OpenTofu Registry and it does not embed credentials. Use only an authorized file and the public first-value flow:

https://www.brainiall.com/transcreve/integracoes/opentofu-transcribe-module-c100

Source rule: review the [OpenTofu Registry](https://opentofu.org/registry/) and its module documentation before any account-level publication.
