# WordPress transcript plugin shape — C103 blueprint

This blueprint keeps WordPress-side handling bounded: the site owner selects
one authorized file, reviews the result, and chooses whether to send it to the
hosted Transcreve flow.

It is not a submitted plugin and contains no automatic upload, tracking secret,
or paid checkout. Follow the [WordPress plugin directory guidelines](https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/)
before packaging a distributable plugin.
