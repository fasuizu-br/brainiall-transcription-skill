# n8n transcript community-node starter — C103 blueprint

This starter shows how a self-hosted n8n workflow can call the metered
BRAINIALL endpoint once for one authorized file and return transcript JSON,
speaker labels, SRT, and WebVTT.

No community-node verification, n8n Cloud install, credential, or paid run is
included. Check the [verified community-node guidance](https://support.n8n.io/article/how-to-access-and-install-verified-community-nodes-in-n8n-cloud-ikdliw666osnehztowktx0hb)
and keep the node unprivileged before any submission.
