# Zapier transcript workflow — C103 blueprint

This recipe maps one user-authorized audio file to a Zapier step that returns
reviewable transcript JSON, SRT, and WebVTT for the next action.

It is a blueprint only: no Zapier account, app-directory listing, customer
credential, or paid run is included. Review the [publishing requirements](https://docs.zapier.com/integrations/publish/integration-publishing-requirements)
before submitting anything publicly.
