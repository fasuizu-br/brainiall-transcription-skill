# VS Code transcript QA extension — C103 blueprint

This recipe describes a local fixture command for reviewing transcript,
speaker labels, and caption files from the IDE. Network access should be
explicit and limited to a user-authorized request.

No publisher account, Marketplace extension, or private audio is included.
Review [VS Code publishing](https://code.visualstudio.com/api/working-with-extensions/publishing-extension)
and the extension permission model before packaging a VSIX.
