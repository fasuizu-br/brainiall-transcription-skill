# C107 registry, plugin and store preflight

Use this note to compare a real transcription job across crates.io, NuGet,
Maven Central, Obsidian, Zotero, Chrome Web Store and Google Play.

## Safe sequence

1. Start with one local, consented or synthetic file and a bounded output.
2. Record first value and an explicit price question before packaging.
3. Read the current publisher/review rules for the target surface.
4. Never put API keys in package metadata, extension bundles or mobile builds.
5. Treat downloads, installs, approvals and checkout redirects as non-revenue.

Official references: [Cargo publishing](https://doc.rust-lang.org/cargo/reference/publishing.html), [NuGet publishing](https://learn.microsoft.com/en-us/nuget/nuget-org/publish-a-package), [Maven Central](https://central.sonatype.org/publish/publish-portal-maven/), [Obsidian developer docs](https://github.com/obsidianmd/obsidian-developer-docs/blob/main/README.md), [Zotero plugins](https://www.zotero.org/support/plugins), [Chrome distribution](https://developer.chrome.com/docs/extensions/how-to/distribute), and [Google Play setup](https://support.google.com/googleplay/android-developer/answer/9859152?hl=en).
