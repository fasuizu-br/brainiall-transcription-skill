# C107 research knowledge workflow

Use a consented interview to create a reviewed Markdown note that can be
attached to a Zotero item or stored in an Obsidian vault. The integration is a
local contract, not a claim of directory listing or plugin approval.

## Acceptance checks

- confirm rights, language, retention and the human reviewer;
- preserve timestamps and speaker labels in the note;
- keep credentials outside fixtures and never request a vault or library dump;
- export a reversible note before asking for payment;
- count a buyer only after a paid order is settled and reconciled.

See [Zotero plugin development](https://www.zotero.org/support/dev/client_coding/plugin_development), [Zotero plugins](https://www.zotero.org/support/plugins), and [Obsidian developer docs](https://github.com/obsidianmd/obsidian-developer-docs/blob/main/README.md).
