# Zendesk support QA transcript — C102 blueprint

This public recipe shows a bounded support-QA flow: an authorized call is
transcribed locally, speaker labels and SRT are reviewed, and an approved
summary can be attached to a ticket by the customer's own integration.

It is not a Zendesk Marketplace submission, approval, installation, or paid
integration. Do not include customer credentials or private audio in an issue
or pull request. Review Zendesk's [Marketplace requirements](https://developer.zendesk.com/documentation/marketplace/)
and [submission steps](https://developer.zendesk.com/documentation/marketplace/publishing-to-the-marketplace/submit-your-app/)
before building a real app.
