# Freshworks transcript QA — C102 blueprint

Use the existing diarized-transcription skill to produce a reviewable artifact
for Freshdesk/Freshservice operations. The output is intentionally staged:
local consent check → transcript/SRT review → customer-controlled ticket update.

This folder is a recipe only. It does not claim Freshworks approval, a live app,
an account, or marketplace revenue. Read the [app submission process](https://developers.freshworks.com/docs/app-sdk/v3.0/support_portal/app-submission-process/)
and [Freshworks app guide](https://developers.freshworks.com/docs/guides/submission-guidelines/submission-process/freshworks-app/)
before a submission.
