# Pipedream transcript component — C102 blueprint

This blueprint maps a Pipedream action to the BRAINIALL API without embedding a
key: accept a user-authorized file reference, call the metered endpoint once,
and return transcript JSON, SRT, and WebVTT for the next workflow step.

No Pipedream account, component publication, customer credential, or paid run
is included. Test with a fixture and review the [component overview](https://pipedream.com/docs/components)
and [contribution API](https://pipedream.com/docs/components/contributing/api)
before contributing to the public registry.
