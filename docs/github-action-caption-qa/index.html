Catch broken captions before they ship.

Validate SRT and WebVTT structure in pull requests: UTF-8, timing syntax, reversed cues, overlaps and missing WebVTT headers. Files stay on the GitHub runner and the action requires no key.

Private by default

PR-ready

Malformed captions fail the job while still publishing outputs, file-line annotations and a bounded job summary.

Copy the workflow

- uses: actions/checkout@v4
- uses: fasuizu-br/brainiall-caption-qa-action@v1.3.0
  with:
    path: captions
    report: artifacts/caption-qa-report.json

What it does not claim

This is structural preflight, not a linguistic accuracy score, readability certification, accessibility certification or speech-to-text provider. Human review remains necessary.
