Diarized Transcription API

Transcrição PT-BR e espanhol, pronta para integrar.

Envie uma gravação explicitamente autorizada e receba JSON com timestamps por palavra e rótulos anônimos de falante. O contrato público descreve somente o endpoint e os campos verificados.

POST /v1/whisper/transcribe, multipart, com idioma pt ou es e diarização.

Limites explícitos

Arquivo local regular de até 25 MB nos clientes seguros; sem URL remota, symlink ou retry automático.
